# SFX Botánica

Sonidos de naturaleza para motion design de estilo botánico: hojas, madera, agua, aves, viento, insectos y ambientes de parque.

Todos los sonidos son **CC0 (dominio público)**: se pueden usar en proyectos comerciales, sin atribución obligatoria. Igual dejamos los créditos abajo.

## Formatos

- **Efectos cortos (one-shots)**: WAV 48 kHz / 24-bit, listos para After Effects, Premiere o DaVinci.
- **Ambientes largos**: MP3 48 kHz / 192 kbps, para que el repo no pese demasiado.
